# YT Playlist Downloader

A personal Chrome/Edge extension that downloads YouTube playlists (or single videos) with
**yt-dlp**. The extension talks to a small Python script on your machine over
[Native Messaging](https://developer.chrome.com/docs/extensions/develop/concepts/native-messaging).
There's no local web server and no open port.

```
popup.html/js ──runtime messages──► background.js (service worker)
                                        │  chrome.runtime.connectNative
                                        ▼  4-byte LE length + JSON over stdin/stdout
                                   host/yt_host.py ──subprocess args list──► yt-dlp ──► ffmpeg
```

## Folder structure

```
yt-download extension/
├── extension/                 ← load this folder as the unpacked extension
│   ├── manifest.json          MV3 manifest (nativeMessaging, storage, activeTab)
│   ├── background.js          owns the native port + job state in chrome.storage.local
│   ├── popup.html / .css / .js
│   └── icons/
├── host/
│   ├── yt_host.py             native messaging host (stdlib-only Python 3.8+)
│   ├── test_host.py           talks to the host like the browser does (for testing)
│   ├── yt_host.bat            ← generated by install (launcher the browser runs)
│   ├── com.ytplaylist.downloader.json  ← generated by install (host manifest)
│   └── yt_host.log            ← host log (stdout is reserved for the protocol)
├── install.cmd / install.ps1     register the host for your extension ID
├── uninstall.cmd / uninstall.ps1 remove the registration
└── README.md
```

## Features

- Fills in the URL from the current tab when it's a playlist, a video, or a video URL with `&list=`.
- Fetches playlist info first (`yt-dlp --flat-playlist -J`) and shows the title and video count.
- The popup works in steps:
  1. **Video or Playlist.** It's picked automatically from the link and you can switch. *Video* on a
     `watch?v=…&list=…` link downloads just that video.
  2. **Paste the link.** It's filled in from the current tab.
  3. **Format:** Video (mp4) at 1080p / 720p / 360p / best, or Audio (mp3) at best / 320 / 192 / 128 kbps.
     You also choose the folder here.
  - **Sizes:** each quality option shows the estimated download size: the whole playlist's total, or
    the single video's size. So does every row in the playlist list, and the total appears under
    **Download all**. Video sizes come from yt-dlp's format list (`yt-dlp -j`, about 1–2 s per video,
    filled in while you look). They match what yt-dlp actually downloads to within about 1%. mp3 sizes
    are bitrate × length: 320/192/128 kbps are exact, and "Best" (VBR) is a rough guess.
  4. **Playlists only:** a **Download all** button, then a list of every video with its own download
     button. A search box helps in long playlists. A single video is sent to yt-dlp as `--playlist-items 7`,
     and the file keeps its real playlist number in the name.
- **Browse…** opens the Windows folder picker. The helper runs it, so you get a real path. The popup
  closes while the dialog is open and reopens with everything as you left it.
- **Toolbar icon:** while downloading, the icon turns into a progress circle for the whole job, so
  you can close the popup and still watch it. When it's done, it shows a **✓** badge (green; amber if
  some videos were skipped) or **!** if it failed. The badge clears when you start a new download.
- Shows live progress: a big percentage for the current video, a "Whole playlist" bar, the
  title, speed and time left. yt-dlp output is
  parsed from `--newline` + `--progress-template`/`--print` lines that are tagged JSON, and turned
  into structured messages.
- The **Cancel** button kills yt-dlp *and* its ffmpeg child (`taskkill /T`).
- Closing the popup doesn't stop the download. The service worker keeps the port open, state lives in
  `chrome.storage.local`, and reopening the popup shows the live progress.
- Output goes to `<folder>/<playlist title>/001 - <title>.mp4`. A single video goes to `<folder>/<title> [id].mp4`.
- Re-running a playlist skips videos you already finished. It uses `--download-archive`, with one archive
  file per folder: `.yt-dlp-archive-video.txt` and `.yt-dlp-archive-mp3.txt` (hidden files).
- Unavailable or private videos are skipped (`--ignore-errors`) and listed at the end.
- Format: `-f "bv*[height<=1080]+ba/b[height<=1080]" --merge-output-format mp4`.
  Audio-only uses `-f ba/b -x --audio-format mp3`.

## Setup (Windows)

### 1. Install the prerequisites

```powershell
winget install Python.Python.3.13      # skip if you already have a working Python 3.8+
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```

Open a **new** terminal and check: `yt-dlp --version` and `ffmpeg -version`.
Then **fully quit the browser** (all windows, and the tray icon too) and reopen it. The browser
starts the host with the PATH it had when *it* started.

### 2. Load the extension

1. Open `chrome://extensions` (Edge: `edge://extensions`).
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick the `extension` folder.
4. Copy the **ID** shown on the extension card. It's 32 letters, like `abcdefghijklmnopabcdefghijklmnop`.

### 3. Register the native host

From this folder:

```powershell
.\install.cmd <your-extension-id>
# Edge, or both browsers:
.\install.cmd <your-extension-id> -Browser Edge
.\install.cmd <your-extension-id> -Browser All
```

You can also double-click `install.cmd` and paste the ID when asked. The script:

- finds Python and writes `host\yt_host.bat` with its full path
- writes `host\com.ytplaylist.downloader.json` with your ID in `allowed_origins`
- registers that manifest under
  `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.ytplaylist.downloader` (and/or the Edge key)
- checks yt-dlp and ffmpeg, then runs a host self-test

No admin rights are needed. If you move the project folder, run the install again.

### 4. Test it

1. Reload the extension on `chrome://extensions` (circular arrow).
2. Open a short public playlist, for example
   `https://www.youtube.com/playlist?list=UU4QobU6STFB0P71PMvOGN5A` (one 19-second video).
3. Click the extension icon. **Playlist** should already be chosen, with the link filled in and the
   playlist title and "1 video" shown.
4. In step 3, choose **Video** or **Audio** and a quality.
5. Click **Download all**, or the download button next to a video. Then close the popup, and reopen it. The progress should still be there.
6. When it's done, click **Download** again for the same playlist. It should report "1 already
   downloaded" and download nothing.

You can test the host without the browser too:

```powershell
py host\test_host.py check
py host\test_host.py info "https://www.youtube.com/playlist?list=UU4QobU6STFB0P71PMvOGN5A"
py host\test_host.py download "https://www.youtube.com/playlist?list=UU4QobU6STFB0P71PMvOGN5A" --quality 360
py host\test_host.py download "<playlist-url>" --items 1,3,5 --audio   # only these positions, as mp3
```

(Press Ctrl+C during a download to send a cancel.)

## Uninstall

```powershell
.\uninstall.cmd              # removes the registry keys and generated files
.\uninstall.cmd -RemoveLogs  # also deletes host\yt_host.log
```

Then remove the extension on `chrome://extensions`. Your downloads and archive files are left alone.

## Troubleshooting

Start with **`host\yt_host.log`**. Every request, the exact yt-dlp command line, and every yt-dlp
error is logged there.

### "Specified native messaging host not found."

The browser can't find a registration for `com.ytplaylist.downloader`.

- You haven't run `install.cmd` yet, or you ran it for a different browser. Edge needs `-Browser Edge`
  or `-Browser All`.
- Check the registration:
  ```powershell
  (Get-Item 'HKCU:\Software\Google\Chrome\NativeMessagingHosts\com.ytplaylist.downloader').GetValue('')
  ```
  It must print the full path to `host\com.ytplaylist.downloader.json`, and that file must exist.
  If you moved or renamed the project folder, run `install.cmd` again.
- The manifest's `"path"` must point at an existing `host\yt_host.bat`.
- Restart the browser after installing. Chrome caches lookups.

### "Access to the specified native messaging host is forbidden."

The host is registered, but your extension's ID isn't in `allowed_origins`.

- Compare the ID on `chrome://extensions` with `host\com.ytplaylist.downloader.json`. The entry must be
  exactly `chrome-extension://<id>/`, with the trailing slash.
- An unpacked extension's ID depends on the folder path. If you load it from another folder or
  another machine, the ID changes. Run `install.cmd <new-id>` again (you can pass several IDs:
  `install.cmd id1,id2`).

### "Native host has exited."

The host started and then quit.

- Run `host\yt_host.bat` by hand. If Python can't start, the error shows there.
- Run `py host\test_host.py check`. A JSON reply means the protocol works.
- See `host\yt_host.log` for a traceback.

### "yt-dlp was not found on PATH" / "ffmpeg was not found on PATH"

Install them (step 1), then **fully** quit and restart the browser so it picks up the new PATH.
If yt-dlp is installed as a Python module rather than an exe, the host falls back to `python -m yt_dlp`.

### "unable to download video data: HTTP Error 403: Forbidden"

YouTube sometimes refuses a stream URL. The helper retries automatically: up to 3 runs, each with fresh
URLs, and the popup shows "Retrying 2/3…". Finished videos are skipped on each retry. If all three
fail, wait a few minutes and try again, and update yt-dlp (`yt-dlp -U`). Starting the same download
again is safe: it continues where it stopped.

### Downloads fail with "Requested format is not available" or "Sign in to confirm you're not a bot"

YouTube changes often. Update yt-dlp first: `yt-dlp -U` (or `winget upgrade yt-dlp.yt-dlp`).
Newer yt-dlp versions need a JavaScript runtime such as [Deno](https://deno.com) to get every format
(`winget install DenoLand.Deno`). See the yt-dlp wiki.

### Progress shows "The download was interrupted"

The browser or extension restarted during a download, which killed the host. Start the download
again: finished videos are skipped, and partial `.part` files resume.

## Notes

- **Security:** the URL is checked on both sides, and the host only accepts YouTube hosts. It
  rebuilds the URL from the validated video and playlist IDs, then passes it after `--` in a
  subprocess **args list** (never `shell=True`). Only your extension ID can launch the host.
- One download runs at a time.
- The quality setting is a *maximum*. If a video has no format at or below that height, yt-dlp
  falls back to the best single file at or below it.
